# Missing Forms Checker

## Goal

Identify forms that may still be outstanding without assuming that every prior-year issuer must issue a current-year form.

## Procedure

1. Build a current-year inventory grouped by form type and issuer.
2. Build an expected-source list from the prior-year return and prior-year source documents.
3. Compare the two lists.
4. For each unmatched prior-year source, check whether the employer/account/investment was still active during the target year.
5. Consider whether the relevant reporting threshold or transaction type would require a form for that year.
6. Classify each gap as:
   - `Potentially missing`
   - `Likely not expected`
   - `Needs verification`
7. Produce a checklist with issuer, expected form, reason it was expected, evidence checked, and next action.

Do not state that a form is legally required without verifying current rules from an authoritative source for that form and tax year.
